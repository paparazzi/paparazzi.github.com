scout_detector module

Scout detector driver.

Receive data from the home-made scoutector module, specially made for IMAV 2026. It detects sound and light emitted by a rescue device hold by people in danger (https://www.espaceprotech.com/product/Detecteur-dimmobilite-MOTION-SCOUT-KTR-MSA).

Based on UAVcan protocol.

Example for airframe file

Add to your firmware section:

<module name="scout_detector"/>

Module functions

Init Functions

These initialization functions are called once on startup.

  • scout_detector_init()

Periodic Functions

These functions are called periodically at the specified frequency from the module periodic loop.

  • scout_detector_report()
    • Frequency in Hz: 2.0
    • Autorun: TRUE
      Periodic function automatically starts after init.
  • scout_detector_sim()
    • Frequency in Hz: 3.0
    • Autorun: TRUE
      Periodic function automatically starts after init.

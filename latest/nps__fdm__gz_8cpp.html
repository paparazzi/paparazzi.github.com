Detailed Description

Flight Dynamics Model (FDM) for NPS using the new Gazebo (gz-sim).

Port of the Gazebo Classic FDM (nps_fdm_gazebo.cpp) to gz-sim (Harmonic and newer). It uses the same models, worlds and airframe defines.

gz-sim only gives access to the simulation state from a System plugin. The PaparazziSystem below is added to an embedded gz::sim::Server, which is stepped from nps_fdm_run_step with a blocking RunOnce call in the same thread, so the shared structs need no locking.

Frames: the worlds keep the Gazebo Classic workaround of a 180 degree heading offset in <spherical_coordinates> (Classic used a WSU frame). With that offset the local x, y, z axes of a world are East, North, Up, as in Gazebo Classic. The heading offset is applied here directly, so the result does not depend on the (changing) frame conventions of gz-math.

Cameras (NPS_SIMULATE_VIDEO) are rendered by the gz Sensors system, which NPS adds to the world. Their images are received over gz-transport and passed to the video thread as with Gazebo Classic.

Not ported yet: the laser range array (NPS_SIMULATE_LASER_RANGE_ARRAY) and the sonar.

ins_ekf2 module

INS and AHRS using the EKF2 of PX4.

The EKF2 and the PX4 libraries it needs are copied in sw/ext/px4_ekf2, where sync_px4_ekf2.py updates them to another PX4 version (see PX4_VERSION there).

All PX4 EKF2 parameters have their PX4 default and can be set in the airframe as INS_EKF2_name for the PX4 parameter EKF2_name (e.g. INS_EKF2_GPS_CTRL, INS_EKF2_HGT_REF, INS_EKF2_MAG_TYPE, INS_EKF2_EV_CTRL, INS_EKF2_OF_CTRL, INS_EKF2_EVP_NOISE, INS_EKF2_IMU_POS_X), and the GNSS checks as INS_EKF2_GNSS_name for GNSS_name (e.g. INS_EKF2_GNSS_REQ_EPH). The GNSS thresholds are the ones of the previous version for the horizontal and speed accuracy (EPH 5 m, speed accuracy 1.0 m/s, PX4 uses 3 m and 0.5 m/s) and of PX4 for the rest (EPV 5 m, 10 s healthy before use). See sw/ext/px4_ekf2/generated/ekf2_params.h and https://docs.px4.io/main/en/advanced_config/parameter_reference.html Sensors are only used when their data arrives, so a sensor enabled in a *_CTRL parameter without that sensor does nothing.

Airspeed and sideslip are only fused in fixed wing flight: always for the fixedwing firmware, and for hybrids flown with the rotorcraft firmware when they set stateSetFixedWingFlight() (rotwing_state does this for the forward flight).

Module configuration options

Configure Options

  • name: INS_EKF2_LOG_INPUTS value: FALSE|TRUE
    Description: Log every EKF input on the SD card (EKF2_INPUT messages in the flight recorder log) to replay the EKF offline with sw/tools/ekf2_replay. The EKF starts once the log is open (SDLOG_START_DELAY is then 2 s by default). Needs the flight_recorder module, in NPS the log is in var/logs/sdlog/AIRCRAFT/FLIGHT_RECORDER
  • name: USE_ALT_LLA_WAYPOINTS value: FALSE|TRUE
    Description: Use LLA altitude instead of LTP z for long distance flight (default=TRUE)

Define Options

  • name: INS_EKF2_OPTITRACK value: FALSE|TRUE
    Description: Indoor configuration with only external vision (e.g. Optitrack): EV position, velocity, yaw and height, no GNSS, magnetometer and barometer, EV noise 0.02 m / 0.05 rad and delay 175 ms (each can be changed)
  • name: INS_EKF2_GPS_CTRL value: 7
    Description: GNSS fusion bitmask: 1 horizontal position, 2 vertical position, 4 velocity, 8 dual antenna heading (EKF2_GPS_CTRL_*)
  • name: INS_EKF2_HGT_REF value: 0
    Description: Height reference: 0 baro (default, PX4 uses 1), 1 GNSS, 2 range finder, 3 external vision (EKF2_HGT_REF_*)
  • name: INS_EKF2_MAG_TYPE value: 0
    Description: Magnetometer: 0 automatic (heading on the ground, 3D in the air), 1 heading, 5 none, 6 only to initialize the heading (EKF2_MAG_TYPE_*)
  • name: INS_EKF2_EV_CTRL value: 0
    Description: External vision fusion bitmask: 1 horizontal position, 2 vertical position, 4 velocity, 8 yaw (EKF2_EV_CTRL_*), 15 with INS_EKF2_OPTITRACK
  • name: INS_EKF2_OF_CTRL value: 1
    Description: Optical flow fusion
  • name: INS_EKF2_RNG_CTRL value: 1
    Description: Range finder height: 0 off, 1 conditional (low and slow), 2 always
  • name: INS_EKF2_DRAG_CTRL value: 0
    Description: Multirotor drag fusion (wind estimation without airspeed sensor)
  • name: INS_EKF2_IMU_CTRL value: 7
    Description: IMU bitmask: 1 gyro bias, 2 accel bias, 4 gravity vector fusion
  • name: INS_EKF2_ARSP_THR value: 0
    Description: Airspeed fusion above this true airspeed [m/s], 0 disables it (fixedwing default 8, 10 for hybrids as PX4 for VTOL)
  • name: INS_EKF2_FUSE_BETA value: 0
    Description: Synthetic sideslip fusion in fixed wing flight (fixedwing default 1, also 1 for hybrids)
  • name: INS_EKF2_AIRSPEED_ID value: ABI_BROADCAST
    Description: ABI sender ID of the airspeed: any sensor, or AIRSPEED_AIR_DATA_ID computed by air_data from a differential pressure sensor (the airspeed estimated from the wind is never used). Choose one when a sensor gives both.
  • name: INS_EKF2_GNSS_CHECK value: (GNSS_CHECK_NSATS|GNSS_CHECK_EPH|GNSS_CHECK_SACC|GNSS_CHECK_FIX)
    Description: GNSS checks before the GNSS data is used (GNSS_CHECK_*), PX4 uses all except jamming (2047)
  • name: INS_EKF2_GNSS_REQ_EPH value: 5.0
    Description: Maximum horizontal position accuracy [m] (PX4 3.0)
  • name: INS_EKF2_GNSS_REQ_EPV value: 5.0
    Description: Maximum vertical position accuracy [m]
  • name: INS_EKF2_GNSS_REQ_SACC value: 1.0
    Description: Maximum speed accuracy [m/s] (PX4 0.5)
  • name: INS_EKF2_GNSS_REQ_NSATS value: 6
    Description: Required number of satellites
  • name: INS_EKF2_GNSS_REQ_PDOP value: 2.5
    Description: Maximum PDOP
  • name: INS_EKF2_GPS_DELAY value: 110
    Description: GNSS measurement delay [ms] (PX4 SENS_GNSS0_DELAY)
  • name: INS_EKF2_GPS_POS_X value: 0
    Description: GNSS antenna X offset from the CoG [m] (also _Y and _Z, PX4 SENS_GNSS0_OFF*)
  • name: INS_EKF2_GPS_YAW_OFFSET value: 0
    Description: Yaw of the dual antenna baseline in the body frame [deg], enables the GNSS heading from RELPOS
  • name: INS_EKF2_GPS_ANTENNA_DISTANCE value: 1.0
    Description: Distance between the two antennas of the dual antenna heading [m], the heading is only used when the measured distance is within INS_EKF2_GPS_ANTENNA_DISTANCE_ERR (not checked when not set)
  • name: INS_EKF2_GPS_ANTENNA_DISTANCE_ERR value: 0.2
    Description: Maximum difference between the measured and the configured antenna distance [m]
  • name: INS_EKF2_GPS_YAW_NOISE value: 0.1
    Description: GNSS heading noise when the receiver gives no accuracy [rad]
  • name: INS_EKF2_RNG_MIN_DIST value: 0.001
    Description: Minimum distance the range finder measures [m]
  • name: INS_EKF2_RNG_MAX_DIST value: 4
    Description: Maximum distance the range finder measures [m]
  • name: INS_EKF2_OF_MAX_RATE value: 200
    Description: Maximum flow rate the optical flow sensor measures [rad/s]
  • name: INS_EKF2_AGL_ID value: ABI_BROADCAST
    Description: ABI sensor ID used as input for AGL measurements
  • name: INS_EKF2_BARO_ID value: ABI_BROADCAST
    Description: ABI sensor ID used ad input for Barometric measurements
  • name: INS_EKF2_GYRO_ID value: ABI_BROADCAST
    Description: ABI sensor ID used as input for gyro measurements
  • name: INS_EKF2_ACCEL_ID value: ABI_BROADCAST
    Description: ABI sensor ID used ad input for acceleration measurements
  • name: INS_EKF2_MAG_ID value: ABI_BROADCAST
    Description: ABI sensor ID used as input for magnetic measurements
  • name: INS_EKF2_GPS_ID value: GPS_MULTI_ID
    Description: ABI sensor ID used ad input for GPS measurements
  • name: INS_EKF2_RELPOS_ID value: ABI_BROADCAST
    Description: ABI sensor ID used ad input for Relative Position heading measurements
  • name: INS_EKF2_EVENT_MSGS value: TRUE|FALSE
    Description: Send the EKF events and status changes (alignment, fusion started/stopped, resets, faults) as INFO_MSG to the flight recorder, and the important ones to the GCS (default: TRUE)
  • name: INS_EKF2_EVENTS_ALL value: FALSE|TRUE
    Description: Send all the EKF events to the GCS, not only the important ones (alignment, dead reckoning, faults); all events always go to the flight recorder (default: FALSE, setting 'all events')
  • name: INS_EKF2_EVENT_HOLDOFF value: 5
    Description: Minimum time between two messages about the same status or event (default: 5 s)
  • name: INS_EKF2_PREFLIGHT_POS value: TRUE|FALSE
    Description: Preflight check: require the configured position source (GNSS or external vision) to be used (default: TRUE)
  • name: INS_EKF2_PREFLIGHT_INNOV_TAU value: 1.0
    Description: Preflight check: time constant of the low-pass filter of the innovation test ratios [s], a filtered ratio above 1 blocks arming
  • name: INS_EKF2_LOG_DEVICE value: flightrecorder_sdlog
    Description: SD log device for the EKF inputs (flightrecorder_sdlog or chibios_sdlog)
  • name: INS_EKF2_LOG_WAIT value: 60
    Description: Maximum time to wait for the log before the EKF starts without logging the inputs [s]
  • name: INS_EKF2_LOG_OUTPUT_DIV value: 10
    Description: Also log the EKF output every this number of updates, to check the replay (0 to disable)
  • name: INS_EKF2_FORCE_NAV_REF value: FALSE|TRUE
    Description: force to use the reference defined in the flight plan and not the one computed by the filter after first good GPS position

Module functions

Init Functions

These initialization functions are called once on startup.

  • ins_ekf2_init()

Periodic Functions

These functions are called periodically at the specified frequency from the module periodic loop.

  • ins_ekf2_update()
    • Running at maximum module frequency.
    • Autorun: TRUE
      Periodic function automatically starts after init.

Datalink Functions

Whenever the specified datalink message is received, the corresponing handler function is called.

  • on message EXTERNAL_POSE call ins_ekf2_parse_EXTERNAL_POSE(buf)
  • on message EXTERNAL_POSE_SMALL call ins_ekf2_parse_EXTERNAL_POSE_SMALL(buf)

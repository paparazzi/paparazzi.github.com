Detailed Description

Get data from Cloud Sensor.

  • compute coef value from PAYLOAD_FLOAT data
    • Liquid Water Content (LWC)
    • Angstrom coef
    • single sensor
  • get already computed LWC from PAYLOAD_COMMAND data

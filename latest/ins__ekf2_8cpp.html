Detailed Description

INS based in the EKF2 of PX4.

The EKF2 and the PX4 libraries it needs are copied in sw/ext/px4_ekf2 (see sync_px4_ekf2.py there). The GNSS checks, which PX4 runs in its sensors module, are done here before the GNSS data is given to the EKF.

uint64_t ekf2_time_us ( uint32_t stamp)
static

Convert a 32 bit timestamp (us) of an ABI message to the 64 bit time of the EKF, so the EKF time keeps increasing when the 32 bit time wraps (after 71 minutes).

Only a step back of more than half the range is a wrap: a time read just before a later one stored by another caller is a little older, and taking it for a wrap would put the EKF time 71 minutes ahead.

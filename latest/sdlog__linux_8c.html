Detailed Description

SD logger for Linux based autopilots (Bebop, ...) and NPS.

Same interface and file layout as the ChibiOS SD logger, so the same modules (flight recorder, high speed IMU logging, ...) can log, and the files can be converted with sd2log: <SDLOG_DIR>/PPRZ/pprzlog_0001.LOG <SDLOG_DIR>/FLIGHT_RECORDER/fr_0001.LOG

void sdlog_report_status ( struct transport_tx * trans,

static

Tell the GCS in words why the logger does not run (no SD card, card full, ...): at the start and every time it goes into error later, and when the configuration could not be written.

A normal start is not reported. Sent with the LOGGER_STATUS message, from the main thread.

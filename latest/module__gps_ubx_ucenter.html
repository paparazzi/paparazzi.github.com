gps_ubx_ucenter module

Ublox GPS autoconfiguration.

Automatically configure any Ublox GPS for paparazzi, for any firmware and INS.

  • automatic baudrate detection (the target baudrate first), then sets the target baudrate
  • detects the receiver port the autopilot is connected to (UBX-CFG-PRT, or UBX-MON-COMMS on the X20)
  • configures the navigation messages and rates, the dynamic model and the 3D fix mode
  • saves the configuration to battery backed RAM and flash

The configuration interface is detected from the protocol version (UBX-MON-VER): receivers without the legacy UBX-CFG messages (protocol 40 and later, e.g. X20) are configured with UBX-CFG-VALSET, the others with the legacy messages (generation 9 also with UBX-CFG-VALSET when it doesn't answer the UBX-CFG-PRT poll). Over I2C the legacy messages are used. With UBX-CFG-VALSET, NAV-PVT is the only navigation message, plus NAV-SAT, NAV-RELPOSNED with RTCM and NAV-DAHEADING (dual antenna heading of the X20D).

Warning: you still need to tell the driver, which paparazzi port you use.

Module configuration options

Define Options

  • name: GPS_UBX_UCENTER_RATE value: 100|200|250
    Description: Measurement period [ms]. Default 200 (5 Hz), 100 (10 Hz) with UBX-CFG-VALSET (X20). When the receiver refuses it 250 with the legacy messages and 200 with UBX-CFG-VALSET
  • name: GPS_UBX_NAV5_DYNAMICS value: NAV5_DYN_PORTABLE|NAV5_DYN_FIXED|NAV5_DYN_STATIONARY|NAV5_DYN_PEDESTRIAN|NAV5_DYN_AUTOMOTIVE|NAV5_DYN_SEA|NAV5_DYN_AIRBORNE_1G|NAV5_DYN_AIRBORNE_2G|NAV5_DYN_AIRBORNE_4G
    Description: Dynamic model used by ublox GPS filter. Default:NAV5_DYN_AIRBORNE_2G
  • name: GPS_UBX_UCENTER_ENABLE_NMEA value: FALSE|TRUE
    Description: Also output NMEA (default FALSE)
  • name: GPS_UBX_UCENTER_SAVE value: TRUE|FALSE
    Description: Save the configuration to battery backed RAM and flash (default TRUE)
  • name: USE_GPS_UBX_RTCM value: FALSE|TRUE
    Description: RTK: output NAV-RELPOSNED (and with the legacy messages also HPPOSLLH and RXM-RTCM, DGNSS mode RTK fixed)
  • name: GPS_UBX_UCENTER_PVT_ONLY value: FALSE|TRUE
    Description: Legacy messages: only NAV-PVT (and NAV-SAT) instead of POSLLH, VELNED, STATUS, SOL and SVINFO
  • name: GPS_UBX_UCENTER_SLOW_NAV_SOL value: FALSE|TRUE
    Description: Legacy messages: NAV-SOL at every 8th solution
  • name: USE_GPS_UBX_RXM_RAW value: FALSE|TRUE
    Description: Legacy messages: raw measurements (only available on U-Blox T versions)
  • name: USE_GPS_UBX_RXM_SFRB value: FALSE|TRUE
    Description: Legacy messages: subframe buffer
  • name: DEBUG_GPS_UBX_UCENTER value: FALSE|TRUE
    Description: Send the replies of the configuration steps in a DEBUG message

Module functions

Init Functions

These initialization functions are called once on startup.

  • gps_ubx_ucenter_init()

Periodic Functions

These functions are called periodically at the specified frequency from the module periodic loop.

  • gps_ubx_ucenter_periodic()
    • Frequency in Hz: 4.
    • Autorun: TRUE
      Periodic function automatically starts after init.
    • Start function: gps_ubx_ucenter_init()
      Executed before the periodic function starts.

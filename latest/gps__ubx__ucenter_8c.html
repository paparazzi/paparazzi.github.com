Detailed Description

Configure Ublox GPS.

After finding the baudrate, the receiver is configured with the legacy UBX-CFG messages, or with the configuration interface (UBX-CFG-VALSET) when it doesn't have them anymore (e.g. X20).

Poll the port configuration (legacy UBX-CFG-PRT), the version (UBX-MON-VER, all receivers) and the port information (UBX-MON-COMMS, generation 9 and later).

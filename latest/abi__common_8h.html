◆ ABI_CHECK_MAIN_THREAD

#define ABI_CHECK_MAIN_THREAD   FALSE

ABI messages must be sent from the main thread (the one running the periodic and event functions): their receivers are not thread-safe.

With ABI_CHECK_MAIN_THREAD every message checks it, and one sent from another thread stops the program at that call (abort in NPS/SITL, halt on ChibiOS), to find it with the debugger. Default TRUE in NPS/SITL, FALSE otherwise. Needs the threads module.

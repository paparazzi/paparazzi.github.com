air_data module

AirData interface.

Combines the barometers, differential pressure, airspeed and temperature sensors, like the IMU combines the gyros, accelerometers and magnetometers.

The drivers send their raw values with their own ABI sender ids (BARO_ABS_RAW, BARO_DIFF_RAW, AIRSPEED_RAW and TEMPERATURE_RAW). Per sensor air_data low-pass filters the raw value and applies the calibration (value = (filter(raw) - offset) * scale), selects the sensor to use (the one of the setting, otherwise the first healthy one in the order of the airframe calibration) and sends it with AIR_DATA_SENDER_ID as BARO_ABS, BARO_DIFF, AIRSPEED and TEMPERATURE. It falls back to the next healthy sensor when one stops sending. It also calculates QNH, true airspeed and AMSL (AltitudeAboveSeaLevel) to fly on "flight levels".

The CalibrateBaro setting lines up the barometers with the one in use, so switching barometers gives no altitude step, and resets the QFE; it is also done at boot for the barometers without an offset in the airframe. The ZeroAirspeed setting zeroes the differential pressures. Both are refused while the motors are armed, unless calib_armed. The differential pressures are not zeroed at boot (it could be a reboot in flight, or wind would give a wrong offset): the ones in DIFF_CALIB use the offset of the airframe (0 by default: the offset of the driver), for the others the preflight checks give an error until ZeroAirspeed is pressed. When the differential pressure at rest is above AIR_DATA_DIFF_REST_MAX a warning is sent at boot and in the preflight checks (it doesn't block arming): check the sensor or press ZeroAirspeed.

It is loaded automatically (by the barometers, pitots, INS and the ap and simulation targets), like the IMU it is not added to the airframe. The configuration goes in a section with prefix AIR_DATA_, for example: <section name="AIR_DATA" prefix="AIR_DATA_"> <define name="AIRSPEED_ID" value="MS45XX_SENDER_ID"> <define name="DIFF_CALIB" type="array"> <field type="struct"> <field name="abi_id" value="MS45XX_SENDER_ID"> <field name="offset" value="12.3"> <field name="filter_freq" value="2"> </field> <field type="struct"> <field name="abi_id" value="UAVCAN_SENDER_ID"> </field> </define> </section> Each sensor is a struct with the fields abi_id, calibrated (offset, scale), offset, scale and filter_freq. The order of a *_CALIB is also the priority of the automatic selection. A sensor with a filter_freq (Hz) is low-pass filtered, a second order Butterworth at the measured rate of the sensor. Without filter_freq it isn't filtered. The airspeedFilter setting changes it for the airspeed sensor in use.

Wind: the estimators (ins_ekf2, ins_mekf_wind, wind_estimator, wind_estimation_quadrotor) and the WIND_INFO datalink message (ground wind estimator or a ground wind sensor like sw/ground_segment/python/wind_sensor/ft742.py) send WIND_RAW with their own ids. air_data selects one like the sensors (the one of windId, otherwise the first healthy estimator, then WIND_INFO), sets it in the state and sends it in AIR_DATA; WIND_RAW sends every source in turn. The WIND_INFO wind (from a ground wind sensor: the wind at the ground) and airspeed are only used without an estimator or airspeed sensor on board, or when forced with windId (WIND_INFO_SENDER_ID). The WIND_INFO temperature is a temperature sensor, only used without an air temperature on board.

Module configuration options

Define Options

  • name: AIR_DATA_BARO_CALIB value: array of structs
    Description: calibration of the barometers, also their priority (see the description)
  • name: AIR_DATA_DIFF_CALIB value: array of structs
    Description: calibration of the differential pressure sensors, the scale is the pitot correction
  • name: AIR_DATA_AIRSPEED_CALIB value: array of structs
    Description: calibration of the airspeed sensors
  • name: AIR_DATA_TEMP_CALIB value: array of structs
    Description: calibration of the temperatures
  • name: AIR_DATA_BARO_ID value: ABI_SENDER_ID
    Description: barometer to use (default: ABI_BROADCAST, the first healthy one)
  • name: AIR_DATA_AIRSPEED_ID value: ABI_SENDER_ID
    Description: differential pressure or airspeed sensor to use (default: ABI_BROADCAST, the first healthy one)
  • name: AIR_DATA_TEMP_ID value: ABI_SENDER_ID
    Description: temperature to use (default: ABI_BROADCAST, an air temperature probe, then a pitot, then a barometer)
  • name: AIR_DATA_BARO_SEND_ID value: ABI_SENDER_ID
    Description: barometer in the BARO_RAW telemetry (default: ABI_BROADCAST, all in turn; ABI_DISABLE for none)
  • name: AIR_DATA_AIRSPEED_SEND_ID value: ABI_SENDER_ID
    Description: airspeed sensor in the AIRSPEED_RAW telemetry (default: ABI_BROADCAST, all in turn; ABI_DISABLE for none)
  • name: AIR_DATA_SEND_ALL_SENSORS value: FALSE|TRUE
    Description: also send every calibrated sensor with its own ABI id (default: FALSE)
  • name: AIR_DATA_TIMEOUT value: 0.5
    Description: minimum time in s without a valid value before a sensor is unhealthy
  • name: AIR_DATA_TIMEOUT_FACTOR value: 5.
    Description: a sensor is unhealthy without a valid value for this times its interval
  • name: AIR_DATA_ALIGN_NB value: 20
    Description: number of values to line up a barometer that starts after the calibration
  • name: AIR_DATA_DIFF_MAX value: 10000.
    Description: differential pressures above this (Pa) are ignored
  • name: AIR_DATA_CALIB_AT_BOOT value: TRUE|FALSE
    Description: line up the barometers and check the differential pressures at rest at boot (default: TRUE)
  • name: AIR_DATA_CALIB_BOOT_DELAY value: 3.
    Description: time after boot of the calibration in s
  • name: AIR_DATA_CALIB_TIME value: 2.
    Description: calibration time in s
  • name: AIR_DATA_DIFF_REST_MAX value: 20.
    Description: maximum differential pressure at rest in Pa, above it a warning is sent at boot and in the preflight checks
  • name: AIR_DATA_CALIB_ARMED value: FALSE|TRUE
    Description: allow the calibration while armed (default: FALSE)
  • name: AIR_DATA_WIND_ID value: ABI_SENDER_ID
    Description: wind source to use (default: ABI_BROADCAST, the first healthy estimator, then WIND_INFO)
  • name: AIR_DATA_WIND_SEND_ID value: ABI_SENDER_ID
    Description: wind source in the WIND_RAW telemetry (default: ABI_BROADCAST, all in turn; ABI_DISABLE for none)
  • name: USE_AIRSPEED_AIR_DATA value: TRUE|FALSE
    Description: set airspeed in state interface (default: TRUE)

Module functions

Init Functions

These initialization functions are called once on startup.

  • air_data_init()

Periodic Functions

These functions are called periodically at the specified frequency from the module periodic loop.

  • air_data_periodic()
    • Frequency in Hz: 10
    • Autorun: LOCK
      Periodic function automatically starts after init and can't be stopped.

Datalink Functions

Whenever the specified datalink message is received, the corresponing handler function is called.

  • on message WIND_INFO call air_data_parse_WIND_INFO(dev,trans,buf)

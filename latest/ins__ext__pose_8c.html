bool ins_ext_pose_check_age ( uint32_t ts)
static

Import External Pose Message.

Check the age of a pose from its capture time. The receive delay (receive time - capture time) includes an unknown clock offset, so the age is taken as the delay above the lowest delay seen recently.

Parameters
tscapture time [ms], 0 if not provided
Returns
true if the pose is recent enough and newer than the previous one

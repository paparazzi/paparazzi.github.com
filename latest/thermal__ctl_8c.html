Detailed Description

Author
Fabien-B fabie.nosp@m.n-b@.nosp@m.githu.nosp@m.b.co.nosp@m.m

Control a thermal camera connected to a companion computer.

See https://github.com/enacuavlab/thermal_imav2026 for more information about the integration of a MLX90640 thermal camera.

Payload is controlled via PAYLOAD_COMMAND messages. Designed for IMAV2026 competition.

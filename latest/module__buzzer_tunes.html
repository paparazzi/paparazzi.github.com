buzzer_tunes module

Play tunes on a passive piezo buzzer

Plays a tune at startup, and any tune on request from the GCS settings. The buzzer is driven with a PWM output, the board defines BUZZER_GPIO, BUZZER_PIN, BUZZER_AF, BUZZER_PWMD and BUZZER_PWM_CHANNEL. On the Cube Orange this is the ALARM pin (TIM2_CH1), on the BUZZER pin (5) of the carrier board USB port. Implementation for ChibiOS.

Example for airframe file

Add to your firmware section: This example contains all possible configuration options, not all of them are mandatory!

<module name="buzzer_tunes">
b'<define name="BUZZER_TUNES_STARTUP_TUNE" value="BUZZER_TUNES_STARTUP" />\n '
b'<define name="BUZZER_TUNES_RTTTL_1" value="&quot;name:d=4,o=6,b=120:c,e,g&quot;" />\n '
b'<configure name="BUZZER_TIM" value="TIM2" />\n '
</module>

Module configuration options

Configure Options

  • name: BUZZER_TIM value: TIM2
    Description: Timer of the buzzer pin

Define Options

  • name: BUZZER_TUNES_STARTUP_TUNE value: BUZZER_TUNES_STARTUP
    Description: Tune at startup (BUZZER_TUNES_x), BUZZER_TUNES_NONE for silence
  • name: BUZZER_TUNES_RTTTL_1 value: "name:d=4,o=6,b=120:c,e,g"
    Description: Custom tunes 1 to 3 (BUZZER_TUNES_RTTTL_1..3) in RTTTL format, set them in an airframe section with type string

Module functions

Init Functions

These initialization functions are called once on startup.

  • buzzer_tunes_init()

Periodic Functions

These functions are called periodically at the specified frequency from the module periodic loop.

  • buzzer_tunes_periodic()
    • Frequency in Hz: 100
    • Autorun: LOCK
      Periodic function automatically starts after init and can't be stopped.
